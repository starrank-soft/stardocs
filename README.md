# StarDocs

Open research drafts and engineering articles about AI-native video editing,
browser media systems, motion graphics, and durable agent runtimes.

The repository is the public writing workspace for StarCut. Drafts are kept in
Git so every meaningful revision has an explicit commit and a reviewable diff.

## Status

These documents are active research and engineering drafts, not final
publications. Sections marked as evidence gaps, experiment tasks, or research
concerns identify claims that still require implementation data or controlled
evaluation.

The material was migrated from `starrank-soft/starcut-monorepo` on
August 17, 2026. Subsequent changes are recorded directly in this repository.
